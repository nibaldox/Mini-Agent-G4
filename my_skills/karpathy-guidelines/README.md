# Karpathy Guidelines Skill

Behavioral guidelines derived from Andrej Karpathy's observations on common LLM coding mistakes.

## Origin

This skill is based on:
- [forrestchang/andrej-karpathy-skills](https://github.com/forrestchang/andrej-karpathy-skills) (14.3k stars)
- Andrej Karpathy's talks on LLM coding pitfalls

## Usage

The agent can invoke this skill when:
- Starting a coding task
- User asks about best practices
- Agent needs guidance on how to approach a problem

## Benefits

Following these guidelines results in:
- Fewer unnecessary changes in diffs
- Fewer rewrites due to overcomplication
- Clarifying questions come BEFORE implementation
- More maintainable, focused code
